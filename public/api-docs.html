SaaS Launchup · Private API

Connect your backend

In the SaaS Launchup workspace, open Profile → Workspace setup → Custom Integrations. Enter a name and description, then choose permissions. Use Select all access only when the integration needs every available permission. Copy the token when it appears; SaaS Launchup will not show it again.

Keep the token in your server’s secret settings. Never put it in browser JavaScript, public HTML, or a URL. The token belongs to one company and expires after 90 days. OAuth 2.0 app authorization is not active yet.

The permissions catalog includes the scopes supplied for integration planning. Selectable scopes marked reserved do not unlock endpoints today. SaaS Launchup saves the requested list and separately fixes the currently effective permissions when the token is issued. Activating a reserved scope later requires a new integration approval.

Examples

Use the pipeline GET response to find a stage ID before creating an opportunity. A contact can refer to a company ID created earlier.

GET /api/v1/private/pipelines
GET /api/v1/private/contacts

POST /api/v1/private/companies
{"name":"Example Co","domain":"example.com"}

POST /api/v1/private/contacts
{"name":"Jordan Lee","email":"jordan@example.com","company_id":"COMPANY_ID"}

POST /api/v1/private/opportunities
{"title":"Example Co — new lead","stage_id":"STAGE_ID","contact_id":"CONTACT_ID","company_id":"COMPANY_ID","value_cents":0}

GET returns up to 100 recent records. POST returns 201 and the new record ID. PATCH accepts an id and fields to change. DELETE requires the matching write permission and a body such as {"id":"CONTACT_UUID","confirmation":"delete"}. Delete is irreversible. Linked companies and templates are protected until related records are removed. An invalid, expired, or revoked token returns 401.

Website form submissions and newly created API leads with contacts receive a follow-up task due the next day. These tasks appear in SaaS Launchup's Calendar view. Automation rules created or changed through this API are saved as drafts; outbound email, SMS, webhooks, and external calendar sync remain paused until their providers and controls are connected. A SaaS Launchup token does not authorize Google, Meta, LinkedIn, X, Reddit, Twilio, Stripe, DNS, or domain accounts.

Documents & Contracts

Choose the document and contract permissions in the Custom Integrations scope list. Existing legacy tokens retain their original Documents access setting.

ResourceGETPOSTPATCH / DELETE
document-templatesList templates; add ?id=UUID for contentCreate a templateEdit / delete when unused

document-send—Prepare delivery of an existing document—

Templates use plain text and may include {{contact.name}}, {{contact.email}}, or {{company.name}}. A template can be marked as a document or contract. Contract signing is not available yet.

POST /api/v1/private/document-templates
{"name":"Proposal","kind":"document","title":"Proposal for {{contact.name}}","body_text":"Hello {{contact.name}}, here is your proposal."}

POST /api/v1/private/documents
{"kind":"contract","title":"Service agreement","body_text":"Agreement text"}

POST /api/v1/private/document-send
{"document_id":"DOCUMENT_UUID","contact_ids":["CONTACT_UUID"]}

POST /api/v1/private/template-send
{"template_id":"TEMPLATE_UUID","contact_ids":["CONTACT_UUID"]}

Delivery requests accept one to ten contacts with email addresses and return 202, sent: false, and status: "awaiting_email_connection". SaaS Launchup records the prepared delivery but does not email it until an outbound email provider and delivery process are connected. Do not treat the 202 response as proof that a recipient received anything.

For a website form builder without server code, open Funnels & Automation → Forms & assessments. Its webhook key is separate from a private API token.
